# 项目入口

本页说明去哪里找使用者自己的环境记录，本身不保存任何 IP、订单、节点、UID、版本或完成状态。

使用者的私有记录写在同目录的 `environment.local.md`（不入库），内容只放指向私有交接文档、运维记录和回退位置的链接。该文件存在时先读它；不存在时向用户确认记录位置，或从其指定的客户端和已登录控制台现场定位，不遍历无关私有资料。

先查记录，再读取本次涉及的实际配置与运行态。记录冲突时不盲目恢复旧地址、供应商或协议；当前现场和当次指令优先。记录里的路径缺失只表示记录不可用，不表示服务已经删除。

模型路由、账号清理等不属于代理维护；共享 VPS 上的其他服务不因本次代理调整成为写集。
