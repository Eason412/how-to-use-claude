# 导入与迁移

## 先确定产物

| 输入 | 能提供什么 | 不能默认提供什么 |
|---|---|---|
| 节点链接／二维码 | 节点协议与认证参数 | 完整规则、策略组、前置代理 |
| 机场订阅 | 节点集合，可能附规则 | 自有扩展和私人链 |
| 客户端完整配置 | 该格式明示的功能 | 其他客户端语义、外部 provider 与本机覆盖 |
| 运行时配置 | 某次合并后的状态 | 可跨设备使用或重启后持久保留 |

回退需要源配置、扩展、选择与依赖；跨设备需要目标客户端能表达的节点、组、规则与更新来源；分享诊断只给脱敏摘要。先检查外部依赖，不执行未知脚本或上传凭证到公共转换站。

## 操作顺序

1. **定名**：先确定短而明确的使用方案名与内部引用。名称描述实际路径；配置走固定 ISP 时不能让用户误以为只是 VPS 裸出口。
2. **准备**：保存受影响旧配置的可恢复副本，备份是否成功必须有回执；区分源文件、客户端内部副本和生成文件。节点数据与规则分开准备，按目标客户端适配。
3. **导入**：用受支持的文件或订阅入口。导入与激活分开；重名按 UID、内容、日期和当前使用标记辨认，不反复导入制造重复项。
4. **读回**：核对实际保存的名称、server／port／type、TLS／SNI／指纹、逐级代理、组成员、规则引用；密码只比较不输出。删除桌面专用路径、控制口和接口参数不等于语义已迁移。
5. **验收**：获相应授权后启用，分别验证连通、路径和分流。一个检测页不能证明国内、受保护和普通三路都正确；固定出口另按 [验收流程](egress-validation.md)。
6. **清理**：新方案通过后删除已授权的旧项，先查引用。删规则文件不等于删节点／订阅；维持一份回退，不累积多套同名备份。

## 按客户端操作

- [Clash Verge／Mihomo](clash-verge.md)：配置 UID、扩展层与扩展合并、provider、运行态与持久源、dialer-proxy、固定入站与版本行为。
- [Windows](windows.md)：客户端与Linux服务器分离、PowerShell／NTFS、TUN服务与WSL独立验收。Windows可使用同一固定出口拓扑，但不是Mac配置的原样复制。
- [Shadowrocket](shadowrocket.md)：节点与配置分离、逐级代理、“代理通过”、备注精确引用、手机镜像、本地传输与手机验收。
- 其他客户端：查实际版本的原生导入、链路、规则、UDP、IPv6和更新能力；未支持字段不能静默丢弃后宣称成功。

其他客户端没有现成适配资料时，先查其当前官方文档和实际 UI／配置，不套用上述字段。VPN 客户端可能仅提供整机隧道、没有链式代理或策略组；这时不能承诺等价分流。

## 临时产物

任务开始确定一个私有临时目录与最终交付位置。只在临时目录放转换文件、截图和测试脚本；固定最终文件名，避免每次重试新建正式文件。收尾按引用确认生产配置未依赖临时目录，再停止临时服务并清理。

用户要求可恢复清理时移入废纸篓并保留恢复映射，不宣称已释放磁盘空间。只处理明确属于本任务的产物，未知文件不按名字猜测删除。

## 跨客户端适配

共同的是用户要求与验收标准，不是一份通用配置文件。桌面与手机可以使用不同客户端或协议，但最终出口、保护范围和例外必须分别验证。

### 适配步骤

1. 读取源端当前有效配置，提取无凭据的域名／CIDR、策略意图和拓扑；凭证私有传输。
2. 确认目标客户端及版本能表达逐级代理、固定策略、故障拒绝、DNS／IPv6和所需接管方式。能力不够时说明结构性差异，不静默丢字段。
3. 将规则数据与客户端语法分开；节点／订阅、策略组、规则、激活模式与更新机制分别映射。建立一个明确源和目标产物，不为一次迁移额外部署转换服务器。
4. 用目标客户端原生格式准备并读回，独立验收其实际流量；仅语法通过或桌面成功不算手机通过。
5. 原生引用稳定后再按授权清理旧项，保留必要内部节点。用户只需看到其需要的使用方案，不强迫手动选择链上每一跳。

### 能力与范围

- iOS 不默认具有桌面进程规则、helper 匹配或固定专口能力；只能域名分流时应明确其范围，不宣称与整应用隔离等价。
- MRS、GEOSITE、脚本、代理组类型和更新方式不是跨客户端标准；简单 DOMAIN／DOMAIN-SUFFIX／IP-CIDR 可作规则数据，但动作与解析仍需目标端验证。
- 更新节点、规则资源与整份远程配置是不同操作；后者可能覆盖本地改动。链式字段与空组策略每端分别读回。
- 用户只授权一台设备时，不同步改其他设备；规则设计可以共享，当前激活状态不能共享推定。

目标端未可用时交付其待导入文件和精确未验收项，不把配置准备完成写成部署完成。
