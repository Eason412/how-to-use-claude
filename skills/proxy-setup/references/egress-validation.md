# 验证与迁移

## 记录与准备

项目状态记录只保留本次目标、源配置与扩展定位、当前客户端／内核、profile／mode／TUN、组选择、产物哈希、证据与回退位置。历史报告只是定位线索，不作为现场通过证明；不在 Skill 引用每轮临时测试报告。

记录一份私有回退：受影响源、扩展、选择、引用映射和必要节点缓存。Unix目录 0700，认证文件 0600；Windows使用最小NTFS访问权限，见 [平台适配](windows.md)。回退必须满足本次出口约束。机场仅提供节点，自有配置负责链和规则。采用客户端支持的 provider／扩展，不把修改下载原文作为长期方案。

先静态检查引用和能力；能用不接管生产 TUN 的隔离实例验证就不切正式组。隔离实例自身可能仍经过现有 TUN，要观察实际路径。当前助手所依赖的链路始终按 [运行维护](../../proxy-maintenance/references/connection-safety.md) 保护；用户要求其他现有连接不动时，也不重启、不清连接、不激活会影响它们的配置；必要时先暂停说明。

需要不中断迁移时，先确认当前客户端能保留旧连接且只把新连接交给新入口；现有 socket 不能假定会自动迁移。验证旧连接保持、新入口的新连接成功后，让旧连接自然结束，再清旧入口及其依赖。无法证明这项能力时只交付已验证候选，不激活。生产链不能在仍有旧连接依赖时按“旧配置”删除。

## 最小验收矩阵

按本次改变选择相关项，固定出口迁移至少核对出口、链与失败行为；不要每次普通文字修改都重复全套公网测试。

| 检查 | 方法与完成判据 |
|---|---|
| 最终出口 | 公共 HTTPS 目标返回期望 IP，同时核对实际入口、chain、规则和 TLS；首页 IP 或 200 不单独算通过 |
| 普通与直连分支 | 各自使用新连接观察，不串进专链；判断直连须考虑现存 TUN |
| 中转／最终出口故障 | 隔离注入超时、拒绝或认证失败，受保护请求失败且无其他出口拨号；范围外请求按其实际依赖判断 |
| 入口故障 | 共用入口的分支都可能失败；不为了“其他流量在线”自动添加不合格回退 |
| 受保护 UDP | 本地合成目标与日志确认拒绝或走合格路径，不能仅看请求失败；其他 UDP 不无故全禁 |
| 未知域名／raw-IP | 本地模拟比较通用与固定入口，标出识别盲区，不冒称识别了全部真实应用 |
| DNS／IPv6 | 分别观察节点和目标解析、字面 IPv6 与失败路径；关闭 AAAA 不替代连接验证 |
| 模式／入口停用 | 隔离验证全局、直连或专口关闭；绕口与应用自动直连另计 |
| 更新／生命周期 | 引用改名、成员为空、坏缓存、解析失败、重载或必要的重启恢复，核对规则、选择与新旧连接；按授权测试 |
| 目标设备／应用 | 各端实际入口、配置和公共请求证据独立确认；禁测真实服务时保留其未验证项 |

公网探针使用明确允许的公共目标、禁止跳转、不带账号或私有正文、限制响应体与超时；本地故障测试用合成域名与 loopback，不发真实受保护服务请求。记录公网、模拟与静态证据的区别，CONNECT 成功不等于目标 TLS／完整路径成功。

## 回退与清理

先保持受保护请求失败或恢复合格旧版本，按本次授权处理相关客户端，不能擅自停全部应用。凭证期间有变化不覆盖新凭证；回退后也检查实际出口、链和模式。

临时云规则、监听和服务执行 [精确清理流程](firewall.md#临时握手与端口测试)。本地只清本次进程、mock、敏感副本和无用文件；保留一个最终产物、一份回退和最小证据，避免按每次重试累积副本。

可恢复清理先查运行依赖、文件引用和归属；配置哈希、当前 profile、mode／TUN与必要的被动连接状态比较前后。不为清理额外发公网或真实服务请求。文件移入废纸篓不表示已释放空间，报告恢复位置。旧报告删除或迁移时同步修复技能中的活链接，但不改写原始历史记录伪造结果。
